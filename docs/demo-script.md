# Сценарий демо — homelab-monitor

Хронометраж: **до 2 минут**. Цель: показать разницу между сырым алертом и алертом
с AI-объяснением на одном и том же инциденте.

## Подготовка (до записи)

- [ ] `docker compose --profile full up -d` — весь стек поднят
- [ ] `.env` заполнен (`GLM_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`)
- [ ] Telegram открыт рядом: видно чат с ботом
- [ ] Grafana открыта: http://localhost:3000, дашборд с CPU/диском
- [ ] Терминал: две вкладки — одна для симуляции, одна для «разбора руками»

## Хронометраж

### 0:00–0:15 — сетап (за кадром можно оставить)

«Домашняя лаба: Prometheus собирает метрики, Loki — логи, правила алертов настроены.
Сейчас покажу, что происходит при инциденте — сначала без агента, потом с ним.»

### 0:15–0:45 — часть 1: сырой алерт

1. Запускаем симуляцию заполнения диска (скилл `incident-sim`): временный файл на диск.
2. Через ~2 минуты срабатывает `HighDiskUsage`.
3. Показываем сырой алерт (Alertmanager/Grafana): «диск > 85%».
4. Показываем «разбор руками»: логинимся, `df -h`, ищем, кто съел место, смотрим логи.
   Комментируем таймер: «вот эти N минут я ищу причину сам».

### 0:45–1:30 — часть 2: алерт с объяснением

1. Чистим диск (cleanup из `incident-sim`).
2. Повторяем ту же симуляцию.
3. В Telegram приходит алерт от агента: **что случилось / вероятная причина / что проверить**.
4. Читаем сообщение вслух, показываем, что причина указана сразу
   (например, «крупный файл в /var/tmp, создан недавно — похоже на тестовую запись»).

### 1:30–1:55 — итог

«Один и тот же инцидент: с сырым алертом разбор занял N минут, с объяснением — M.
Данные по замерам — в README, проект демо, цифры из локальных замеров.»

## Что фиксируем для замеров (демо)

| Замер | Сырой алерт | Алерт с объяснением |
|---|---|---|
| Время до формулировки гипотезы о причине | ? мин | ? мин |
| Доля ложных срабатываний за демо-период | — | ? % |

## Чек-лист записи

- Таймер на экране или таймкод в монтаже
- Терминал крупным шрифтом
- Telegram-сообщение агента показать фуллскрином хотя бы 3 секунды
- Не показывать `.env` и токены в кадре
